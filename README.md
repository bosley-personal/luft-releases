# Luft for Mac

Open this page on the Mac where you want to install Luft. The download is a Mac app and will not install on a phone or tablet.

On your Mac, open the [latest release page](https://github.com/bosley-personal/luft-releases/releases/latest), choose **Luft.zip** under Assets, unzip it, and move Luft.app to Applications. Luft requires macOS 14 or later.

Stockfish 19 is included for playing and analysis. You only need **Luft.zip**; the separate Stockfish archive under Assets provides its GPLv3 license and source code.

The app is not Apple notarized. On first launch, try opening it once, then use System Settings → Privacy & Security → Open Anyway if macOS blocks it. Luft checks for signed updates automatically after installation; the app's Luft menu also has Check for Updates.

On first launch, Luft offers an optional reference database download of about 6 GB. The data contains games from [Lumbra's Gigabase](https://lumbrasgigabase.com/en/) (CC BY-NC 4.0, noncommercial use) and [The Week in Chess](https://theweekinchess.com/). Luft can be used without the reference database, and the download can be started later from Settings → Reference.

The source repository is private. This repository contains only release files and the Sparkle update feed.
